System Prompt
Every run sends one prompt message = auto environment briefing (who the model is, turn budget, tools, approval waitlist) + your custom text + task brief. You control how that message is delivered:
Preview — what the model actually receives

Tool Permissions
Read-only lorebook inspection (list / search / get) is always on in agent mode. These toggles control which proposal actions the model may stage for your review. Nothing is ever written without you accepting it in the Feed.
Injected Context
Entries injected directly into the prompt each run — no tools needed. Works for non-active lorebooks (e.g. a status tracking lorebook).
Linked Lorebooks (dynamic)
Whole lorebooks scanned at run time with SillyTavern's own keyword activation (keys, selective logic, probability, budget). Pinned entries are always injected. Uses ST's live World Info settings — no separate config.
Per-Character Rules Different injected context + task per character. When the current chat's character matches a rule, the agent uses that rule's picks and overrides; otherwise the fallback below applies.
